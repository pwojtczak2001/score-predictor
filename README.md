# Score Predictor

A web application for predicting football match results.

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Microsoft SQL Server
- Jackson
- Maven

## Current Features

- Import teams from JSON
- Import matches from JSON
- Prevent duplicate teams
- Prevent duplicate matches

## Planned Features

- User accounts
- Private leagues
- Match predictions
- Automatic score synchronization
- Leaderboards
